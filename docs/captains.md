## Merge Captain Responsibilities

- Coordinate pull request reviews.
- Make sure required tests pass before merging.
- Help resolve merge conflicts.
- Keep the main branch stable.
- Coordinate merges during the sprint.
- Communicate with teammates about pending PRs and blockers.

## Deputy Responsibilities

- Assist the merge captain.
- Help coordinate pull request reviews.
- Serve as backup when the captain is unavailable.
